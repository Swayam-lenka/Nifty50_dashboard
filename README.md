# Nifty 50 Financial Stock Dashboard

A Python-based dashboard for analyzing Nifty 50 stocks.

## Features
- Risk–Return scatter plot
- Sector-wise YTD performance visualization
- Beta distribution analysis
- Sector heatmap
- Sharpe ratio screener
- CSV export of ranked stocks

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python nifty50_dashboard.py
```

## Libraries Used
- pandas
- numpy
- matplotlib
- seaborn
- plotly (optional)
